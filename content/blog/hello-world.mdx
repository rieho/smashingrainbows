This is the first entry in the experiments journal. The goal is to have a place where I can quickly prototype UI ideas, document interaction patterns, and share working code.

## Why this exists

Most design tools are great for static mockups but fall short when documenting:

- Micro-interactions and animation curves
- State transitions and edge cases
- Responsive behavior across breakpoints
- Accessibility considerations in interactive components

This site bridges that gap — every experiment includes a live, editable code playground.

## A quick demo

Here's a simple React component you can edit live:

<Playground
  files={{
    "/App.js": `import { useState } from "react";

export default function App() {
  const [count, setCount] = useState(0);

  return (
    <div style={{
      display: "flex",
      flexDirection: "column",
      alignItems: "center",
      justifyContent: "center",
      minHeight: "100vh",
      fontFamily: "Inter, system-ui, sans-serif",
      gap: "1rem",
    }}>
      <p style={{ fontSize: "4rem", fontWeight: 600, margin: 0 }}>
        {count}
      </p>
      <button
        onClick={() => setCount(c => c + 1)}
        style={{
          padding: "0.5rem 1.5rem",
          fontSize: "1rem",
          border: "1px solid #e5e5e5",
          borderRadius: "0.5rem",
          background: "#fafafa",
          cursor: "pointer",
        }}
      >
        Increment
      </button>
    </div>
  );
}`,
  }}
/>
