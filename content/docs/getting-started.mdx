## Adding a new doc page

Create a new `.mdx` file in `content/docs/`:

```
content/docs/my-experiment.mdx
```

Add frontmatter at the top:

```mdx
---
title: My Experiment
description: A short description of what this explores.
---

Your content here.
```

Then add the filename (without extension) to `content/docs/meta.json` to control sidebar ordering.

## Adding a blog post

Create a new `.mdx` file in `content/blog/`:

```
content/blog/my-post.mdx
```

```mdx
---
title: My Post Title
description: What this post is about.
date: 2025-01-15
---

Your content here.
```

## Using the Playground

You can embed live code playgrounds in any MDX file:

```mdx
<Playground
  files={{
    "/App.js": `export default function App() {
  return <h1>Hello</h1>;
}`,
  }}
/>
```

The playground supports `react`, `react-ts`, `vanilla`, `vanilla-ts`, and `static` templates.
