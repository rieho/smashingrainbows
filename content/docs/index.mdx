This is the documentation home for the experiments lab. Use the sidebar to navigate through documented patterns and components.

## What's here

- **Patterns** — Reusable interaction patterns with code examples
- **Components** — Custom UI components built during experiments

## Quick start

Every experiment includes a live playground you can edit directly in the browser. Look for the `<Playground />` component in any doc page.
